#  TrafficRwa CDN

**Content Delivery Network for TrafficRwa OffLite**

Official CDN repository hosting educational traffic sign images and assets for the TrafficRwa OffLite web application.

- **Purpose**: CDN hosting for traffic sign images

## 🌐 CDN Usage

This repository is configured for use with **jsDelivr CDN** for fast, reliable content delivery.

### Base CDN URL:
```
https://cdn.jsdelivr.net/gh/shmwamos/trafficrwa-cdn/
```

### Example Image URLs:
```
https://cdn.jsdelivr.net/gh/shmwamos/trafficrwa-cdn/A.11.webp
```

### Usage in Code:
```javascript
// React/JavaScript
const imageUrl = `https://cdn.jsdelivr.net/gh/shmwamos/trafficrwa-cdn/${signId}.webp`;

// HTML
<img src="https://cdn.jsdelivr.net/gh/shmwamos/trafficrwa-cdn/A.11.webp" 
     alt="Traffic Sign A.11" />
```
